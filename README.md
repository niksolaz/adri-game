# Adriana e i Cuoricini 💗

Platformer 2D mobile: Adriana lancia cuoricini ai bambini arrabbiati per renderli buoni. 3 stelline a partita, se le perdi tutte ricominci da capo. Nessuna registrazione.

Vedi [PIANO.md](./PIANO.md) per il piano d'azione completo.

## Avvio

```bash
npm install
npm run dev   # http://localhost:3000
```

## Controlli

- **Browser:** frecce ← → per muoversi, ↑ per saltare, SPAZIO per lanciare cuoricini
- **Touch:** tocca a sinistra/destra (metà bassa) per muoverti, tocca la metà alta per saltare + lanciare

## Build mobile (Fase 5)

```bash
npm run cap:sync
npx cap add android   # prima volta
npx cap open android
```
